# 📔 Estudo-JavaScript

Repositório dedicado ao armazenamento de códigos, exercícios, projetos e anotações teóricas criados durante a minha jornada de aprendizado na linguagem **JavaScript**.

O objetivo deste espaço é registrar a minha evolução técnica, servindo como uma biblioteca de consulta rápida para os conceitos fundamentais e avançados do ecossistema JS (tanto no Front-end quanto no Back-end).

---

## 🚀 Tecnologias e Ferramentas Utilizadas

* **Linguagem Principal:** JavaScript (ECMAScript Moderno)
* **Ambiente de Execução:** Node.js
* **Frameworks & Bibliotecas:** Express (Construção de APIs Restful)
* **Banco de Dados:** PostgreSQL (Persistência de dados)
* **Testes de Requisições:** Insomnia
